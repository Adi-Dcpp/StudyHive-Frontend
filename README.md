# StudyHive Frontend 🎨

Frontend application for **StudyHive**, a collaborative learning platform built with React and Vite.

> This repository contains only the frontend implementation. For complete project documentation, architecture, API details, and backend setup, please refer to the backend repository.

## Local Setup

```bash
git clone https://github.com/Adi-Dcpp/StudyHive-Frontend.git

cd StudyHive-Frontend

npm install

npm run dev
```
